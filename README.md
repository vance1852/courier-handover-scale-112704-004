# 交接台秤的去皮验证与分装净重

这个项目保存骑手服务站的合成设备资料和本地回放程序。设备能力、时钟和物理证据约定见 [设备资料](protocol.md)。

使用 Python 3.11 标准库。在项目根目录运行 python3 bench.py 查看当前记录，运行 python3 -m unittest discover -s tests -v 核对资料以及本机 HTTP 消息。python3 bench.py --listen 8765 启动回放端，--scene 可另选同格式的观测。回放不接管物理设备。

## 裁定引擎

`weighing.py` 从原始观测出发，按“真正生效的秤档与测量跨度”解释每一次读数，并给出手续结论。它不修改 `bench.py` 的回放职责，只读 `devices.json`、`policy.json` 与观测。

```
python3 weighing.py                 # 全部任务的结单与剩余物结论
python3 weighing.py --task T1       # 只看某任务
python3 weighing.py --seq 14        # 解释某条称量（可重复 --seq）
python3 weighing.py --json          # 机器可读输出
python3 weighing.py --devices D --policy P --scene S   # 换一套项目资料
```

### 读数如何被解读

- **有效秤档**：`observe` 自报的 `mode` 只有与本次开机登记的档一致才生效；不一致时按开机档解读并记为 `notice`。
- **稳定**：称量跨度（`through - at`）不短于设备 `stable_ms`，且显示值落在该档最小显示步长的网格上，才叫稳定数字。稳定门槛、量程、步长任一不满足为 `hold`。
- **去皮**：秤端去皮只在同一次开机内、该 `zero_id` 最近一次阶段为 `effective` 时成立。只回 `received`、或零点定义之后设备重连，都不算生效。未生效的 `net` 读数只留待查，不参与净重。
- **不重复扣皮**：生效的秤端皮重已从显示值里扣掉，独立登记的容器皮重不得再减一次。
- **容器**：标签给出称量期间同在台面的嵌套组合（父筐套副筐）。独立登记的已知皮重只在容器身份与干湿条件都相符、且登记值本身落在生效步长网格上时可用；标签缺失即为“只看到稳定数字却不知道加了哪些物件”，记为 `hold`。
- **旁路接触**（`side_touch`）：读数不能作为干净的增减依据，记为 `hold`。

### 交接与分装

- 结单必须显式引用前后两次称量；设备上的去皮不会被自动归到任何一张单。
- 两次称量只有在容器组合与干湿条件一致（同一实物基准）时才按差值办理。换掉子筐会让基准断裂（`broken`），并提示须对哪条余物称量补称。
- 对外净重只舍入一次（半步进位，按 `legal_step_g`），记录同时保留舍入后的 `net_g` 与未舍入的 `net_raw_g`（及区间 `net_raw_interval_g`）。
- 剩余物校验用“旧结单后的余量与换容器后的新称量区间”互证。落在容差（法定步长）内即可继续办理；新称量上限若超过已结清余量则判 `broken`，不得透支。

### 结论状态

| 状态 | 含义 |
| --- | --- |
| `clean` | 依据完整，可据此办理 |
| `notice` | 有需留意之处（如自报秤档与开机档不符、对外数字与核算不符），仍可办理 |
| `open` | 任务已开单但尚无交接或结单 |
| `hold` | 有数字但不能据此办理，须补证 |
| `broken` | 实物基准断裂或透支，只能办理证据连续的部分 |

### 扩展

`Ledger` 由 `devices.json` 与 `policy.json` 构造，可整体替换：换秤只需在 `scale.modes` 增加档位，换筐只需在 `containers` 增加条目，班组即可用同一套规则重复办理。结单记录的 `signers` 串起“哪张单、由哪个终端、引用哪几条设备读数与哪个容器标签签收”。`tests/test_weighing.py` 覆盖上述各条判定。
